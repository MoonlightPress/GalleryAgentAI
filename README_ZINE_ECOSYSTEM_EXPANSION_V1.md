
# Zine Ecosystem Expansion v1

This is the first version of the broad book/zine ecosystem map.

It creates:

- zine ecosystem seed list
- ecosystem summary
- 30/60-day battle plan
- dashboard export JSON

## Run

```powershell
python run_zine_ecosystem_expansion_v1.py
```

## Check

```powershell
notepad reports\zine_ecosystem_seed.md
notepad reports\zine_ecosystem.md
notepad reports\zine_battle_plan.md
```

## Outputs

```text
memory/zine_ecosystem_seed.json
memory/zine_ecosystem_summary.json
memory/zine_battle_plan.json
```
