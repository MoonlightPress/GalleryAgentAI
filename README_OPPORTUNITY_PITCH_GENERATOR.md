
# Opportunity Pitch Generator

This creates artist-facing explanations that make opportunities feel specific and relevant.

## Run

```powershell
python run_opportunity_pitch_generator.py
```

## Check

```powershell
notepad reports\opportunity_pitches.md
notepad reports\shiny_opportunity_cards.md
```

Outputs:

```text
memory/opportunity_pitches.json
deploy_data/opportunity_pitches.json
reports/opportunity_pitches.md
reports/shiny_opportunity_cards.md
```
