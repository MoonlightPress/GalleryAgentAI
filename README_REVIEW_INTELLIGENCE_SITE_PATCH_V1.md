# Review Intelligence Site Patch v1

Adds a **Review Intelligence** section to the Streamlit site.

This does not redesign the site. It simply puts the useful sprint reports where you can review them.

## Run from project root

```powershell
python run_review_intelligence_site_patch_v1.py
```

## Launch

```powershell
python -m streamlit run app.py
```

## Reports shown

- Ecosystem Summary
- Gallery Fit Analysis
- Gallery Tiers
- Gallery Profiles
- Verified Competitions
- Competition Candidates
- Ecosystem Battle Plans
- Opportunity Rankings
- Fair Ecosystem
- Open Call Verification
