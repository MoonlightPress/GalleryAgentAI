
# Nin Similarity Engine

Compares extracted artist career data against Nin's opportunity profile.

## Run

```powershell
python run_nin_similarity_engine.py
```

## Check

```powershell
notepad reports\nin_artist_matches.md
notepad reports\opportunity_similarity_map.md
notepad reports\nin_opportunity_recommendations.md
```

Outputs:

```text
memory/nin_artist_matches.json
memory/opportunity_similarity_map.json
memory/nin_opportunity_recommendations.json
reports/nin_artist_matches.md
reports/opportunity_similarity_map.md
reports/nin_opportunity_recommendations.md
```
