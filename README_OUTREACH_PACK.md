
# Outreach Pack Builder

This package runs after the submission intelligence package.

It creates:

- actionable target shortlist
- outreach email drafts
- portfolio preparation checklist
- do-not-waste-time list

## Run after `run_submission_intelligence.py`

```powershell
python run_outreach_pack.py
```

## Check

```powershell
notepad reports\actionable_target_shortlist.md
notepad reports\outreach_email_index.md
notepad reports\portfolio_prep_checklist.md
notepad reports\do_not_waste_time.md
```

Email drafts are saved in:

```text
drafts/outreach_emails/
```
