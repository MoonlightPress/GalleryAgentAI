
# Opportunity Ecosystem Expander

Builds evidence chains behind opportunity recommendations.

## Run

```powershell
python run_opportunity_ecosystem_expander.py
```

```powershell
notepad reports\opportunity_ecosystems.md
notepad reports\ecosystem_density_scores.md
notepad reports\opportunity_career_path_report.md
```

reports/ecosystem_density_scores.md
