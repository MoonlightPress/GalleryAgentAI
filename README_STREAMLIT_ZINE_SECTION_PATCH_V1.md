
# Streamlit Zine Section Patch v1

This is the correct patch for the existing `app.py`.

It adds a visible **Zines / Artist Books** section above the current strategy homepage in the first tab.

## Run from project root

```powershell
python run_streamlit_zine_section_patch_v1.py
```

## Then run the app

```powershell
python -m streamlit run app.py
```
