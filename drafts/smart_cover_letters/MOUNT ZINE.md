# Smart Cover Letter — MOUNT ZINE

Tone:
focused and editorial

Recommended Body of Work:
Architecture / Memory / Place

Core Fit:
A permanent zine shop (not a one-off fair) that accepts all genres with no fee and no screening, stocking 150+ titles — a clean ambient-visibility target for artist-book or print work. Recruitment opens twice yearly; the next window is autumn 2026.

Draft Structure:

1. Short greeting
2. Brief introduction
3. Mention why the venue/publication specifically fits the work
4. Mention the body of work
5. Offer portfolio/PDF/Instagram
6. Thank them briefly

Important:
- Do not make the message too long.
- Avoid sounding desperate.
- Avoid generic praise.
- Match the emotional tone of the institution.
