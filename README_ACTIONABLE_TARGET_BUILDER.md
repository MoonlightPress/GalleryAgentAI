
# Actionable Target Builder

This converts partially researched opportunities into structured submission targets.

It does **not** guess missing fields. Unknown fields remain `unknown`.

## Run

```powershell
python run_actionable_target_builder.py
```

## Check

```powershell
notepad reports\actionable_now.md
notepad reports\actionable_targets_export_report.md
```

## Outputs

```text
memory/actionable_targets.json
deploy_data/actionable_targets.json
reports/actionable_now.md
```
