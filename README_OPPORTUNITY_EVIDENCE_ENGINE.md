
# Opportunity Evidence Engine

This tries to strengthen each recommendation with concrete evidence:

- past exhibitors / participants
- artist names
- publishers / bookstores / galleries
- evidence links
- useful descriptive page text

## Run

```powershell
python run_opportunity_evidence_engine.py
```

## Check

```powershell
notepad reports\opportunity_evidence.md
notepad reports\opportunity_quality_board.md
```

Outputs:

```text
memory/opportunity_evidence.json
memory/opportunity_quality_board.json
deploy_data/opportunity_evidence.json
deploy_data/opportunity_quality_board.json
reports/opportunity_evidence.md
reports/opportunity_quality_board.md
```
