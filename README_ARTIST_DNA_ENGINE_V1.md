
# Artist DNA Engine v1

This is the personal-fit layer.

It does not crawl more data. It asks whether each opportunity fits the artist's actual direction.

## Run

```powershell
python run_artist_dna_engine_v1.py
```

## Check

```powershell
notepad reports\artist_dna.md
notepad reports\opportunity_type_classifications.md
notepad reports\artist_fit_scores.md
notepad reports\artist_fit_briefs.md
```

Outputs:

```text
memory/artist_dna.json
memory/opportunity_type_classifications.json
memory/artist_fit_scores.json
memory/artist_fit_briefs.json
deploy_data/artist_dna.json
deploy_data/artist_fit_scores.json
deploy_data/artist_fit_briefs.json
```
