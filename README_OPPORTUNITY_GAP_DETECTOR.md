
# Opportunity Gap Detector

Identifies which missing facts would most improve each opportunity.

## Run

```powershell
python run_opportunity_gap_detector.py
```

## Check

```powershell
notepad reports\opportunity_gaps.md
notepad reports\targeted_research_queue.md
```

Outputs:

```text
memory/opportunity_gaps.json
deploy_data/opportunity_gaps.json
reports/opportunity_gaps.md
reports/targeted_research_queue.md
```
