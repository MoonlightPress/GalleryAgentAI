
# Career Channel Engine

This is the channel-level strategy layer.

It turns opportunities into career branches:

- Zines
- Artist Books
- Illustration Galleries
- Small Press Publishers
- Print Markets
- Instagram / TikTok

## Run

```powershell
python run_career_channel_engine.py
```

## Check

```powershell
notepad reports\career_overview.md
notepad reports\career_channels.md
notepad reports\career_battle_plans.md
```

Outputs:

```text
memory/career_channels.json
memory/career_battle_plans.json
memory/career_overview.json

deploy_data/career_channels.json
deploy_data/career_battle_plans.json
deploy_data/career_overview.json

reports/career_channels.md
reports/career_battle_plans.md
reports/career_overview.md
```

## Important

The local density numbers are targets/placeholders until a dedicated local crawler is added.

Example:
- 3 Koenji zine shops
- 1 Nakano shop
- 10 within 20km of Koenji

The next high-value crawler should populate those counts with real places.
