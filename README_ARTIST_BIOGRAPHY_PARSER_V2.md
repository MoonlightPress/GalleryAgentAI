
# Artist Biography Parser v2

Turns validated biographies into structured career evidence.

## Run

```powershell
python run_artist_biography_parser_v2.py
```

## Check

```powershell
notepad reports\parsed_artist_biographies.md
notepad reports\artist_career_graph.md
notepad reports\artist_career_relevance_summary.md
```

Outputs:

```text
memory/parsed_artist_biographies.json
memory/artist_career_graph.json
reports/parsed_artist_biographies.md
reports/artist_career_graph.md
reports/artist_career_relevance_summary.md
```
