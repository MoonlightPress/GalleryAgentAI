
# Application Packet Builder

Turns submission checklists into artist-facing application packets.

## Run

```powershell
python run_application_packet_builder.py
```

## Check

```powershell
notepad reports\application_packets.md
notepad reports\artist_daily_tasks.md
```

Outputs:

```text
memory/application_packets.json
deploy_data/application_packets.json
reports/application_packets.md
reports/artist_daily_tasks.md
```
