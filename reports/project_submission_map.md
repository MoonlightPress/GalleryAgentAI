# Project Submission Map

This turns project concepts into concrete submission paths.

## Neighborhood Memory

### Best First Version
- Format: photobook / zine sequence
- Length: 12–20 images
- Statement: 80–120 words
- Delivery: PDF + Instagram/website link

### Best First Targets
- Tokyo Art Book Fair
- UTRECHT
- ILOVETOYS / neuprint — Chinese Illustration Feature
- B&B Shimokitazawa
- Women United ART MAGAZINE Issue XIV Summer 2026

### What To Prepare
- 12–20 image edit
- 1 short title
- 1 sentence project description
- 80–120 word statement
- 3-line email
