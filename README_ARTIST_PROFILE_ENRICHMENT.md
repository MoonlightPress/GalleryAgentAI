
# Artist Profile Enrichment

Turns raw historical entities into usable artist/profile records.

## Run

```powershell
python run_artist_profile_enrichment.py
```

## Check

```powershell
notepad reports\artist_profiles.md
notepad reports\artist_clusters.md
notepad reports\opportunity_artist_map.md
```

Outputs:

```text
memory/artist_profiles.json
memory/artist_clusters.json
memory/opportunity_artist_map.json
reports/artist_profiles.md
reports/artist_clusters.md
reports/opportunity_artist_map.md
```
