
# Submission Requirements Extractor

Creates artist-facing preparation checklists.

## Run

```powershell
python run_submission_requirements_extractor.py
```

## Check

```powershell
notepad reports\submission_checklists.md
```

Outputs:

```text
memory/submission_checklists.json
deploy_data/submission_checklists.json
reports/submission_checklists.md
```
