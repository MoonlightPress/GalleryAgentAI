# Deep Research Prompt for Artist Career Profile

Create an extremely comprehensive, sourced career profile for the artist [ARTIST NAME].

Search:
- official website
- Instagram
- Chinese-language web
- Japanese-language web
- English-language web
- publisher pages
- book/zine listings
- gallery pages
- exhibition announcements
- art fair pages
- interviews
- collector/shop pages
- archived event listings

Find:
1. Full name / artist names / alternate spellings
2. Artist statement or self-description
3. Published books, zines, catalogs, magazines
4. Solo/group/cafe/gallery/fair/popup exhibition history
5. Sales evidence: collectors, shop listings, sold work, installation photos
6. Press mentions, interviews, captions by galleries
7. Recurring themes and visual language
8. Geographic pattern: China / Tokyo / Japan / international
9. Peer artists, collaborators, galleries, publishers, shops
10. Career stage assessment
11. Strategic next opportunities
12. Bad-fit opportunities
13. 6–12 month roadmap

Output:
- artist_master_profile.json fields
- artist_research_profile.md long report
- timeline table
- source list with URLs
- confidence notes for every claim

Rule:
Separate FACTS from INTERPRETATION.
Do not invent missing exhibition history. Mark unknowns clearly.
